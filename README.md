## 📌 Overview

The **House Price Predictor** helps buyers, sellers, and real estate professionals estimate property values accurately based on historical housing data. By analyzing core features such as square footage, number of bedrooms, location quality, and property age, the app delivers fast and reliable real estate valuations.

---

## ✨ Features

- **Interactive UI:** Dynamic input controls (sliders, numeric inputs, and dropdowns) powered by Streamlit.
- **Instant Price Estimations:** High-precision real-time predictions generated by trained regression models.
- **Interactive Visualizations:** Rich, interactive exploratory plots and model insight charts generated with Plotly.
- **Feature Impact Analysis:** Visual breakdown showing how individual property features affect overall pricing.
